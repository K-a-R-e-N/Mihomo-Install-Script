## Скрипт автоматической установки ядра Mihomo (AmneziaWG) на Raspberry Pi
_Mihomo Proxy-Provider Installation Script_

Профессиональный скрипт для автоматического развертывания и инициализации последней стабильной версии ядра Mihomo (Clash Meta) с нативной поддержкой протокола AmneziaWG. Скрипт превращает вашу Raspberry Pi в умный шлюз, который автоматически перенаправляет заблокированный трафик через туннель WARP, полностью изолируя домашнюю сеть умного дома от любых сетевых сбоев.

![logo](https://sprut.ai)   

### Реализованные функции
* **Режим Proxy-Provider:** Архитектура скрипта полностью разделяет исполняемое ядро и ваши персональные ключи. Конфигурация AmneziaWG вынесена в изолированный ... файл-провайдер `warp.yaml`. Вы можете обновлять ключи в любое время без перезаписи основного установщика.
* **Глобальная нативная утилита `mihomoimport`:** Скрипт регистрирует в операционной системе Linux глобальную команду `mihomoimport`. Обновить ключи можно из абсолютно любой директории терминала за 5 секунд без ввода путей.
* **Жесткая блокировка IPv6:** На уровне конфигурации ядра полностью отключена маршрутизация IPv6, что предотвращает утечки трафика и гарантирует стабильную работу комплексных тестов проверки сети.
* **Защита локального трафика умного дома:** Использование сетевого стека `gvisor` совместно с опцией `bypass-lan: true` полностью исключает домашнюю подсеть (192.168.1.x) из зоны действия VPN. Доступ по SSH, VNC, Homebridge Config UI X и связь между Zigbee/Wi-Fi девайсами никогда не пропадут.
* **Автономность при сбоях питания:** В манифест службы `systemd` встроена задержка перезапуска `RestartSec=5`. Если плата перезагрузится после отключения электричества, туннель будет безопасно дожидаться старта роутера, не нагружая систему.
* **Интеллектуальный интерфейс:** Установка адаптирована под контрастный стиль. Огромные текстовые логи конфигураций из буфера обмена автоматически стираются с экрана сразу после нажатия `Ctrl + D`, оставляя терминал идеально чистым.
* **Комплексный автоматический тест:** На финише скрипт замеряет исходный IP, поднимает туннель, выводит сравнительную таблицу IPv4-адресов и пингует внешнюю сеть для подтверждения успешного обхода блокировок.

### ПРЕДВАРИТЕЛЬНАЯ ПОДГОТОВКА
Прежде чем начать, убедитесь, что на вашей Raspberry Pi установлена актуальная 64-битная версия операционной системы (Raspberry Pi OS / Debian), а также установлены базовые сетевые утилиты `curl` и `git`. Введите следующую команду в консоль терминала:

```bash
sudo rm -Rf /var/lib/apt/lists
sudo apt update && sudo apt install git curl wget -y
#Готово
```

### УСТАНОВКА И ПЕРВЫЙ ЗАПУСК
Скрипт автоматически скачает последнюю стабильную версию ядра, настроит конфигурационные файлы, системную службу автозапуска и выведет контрастную пошаговую инструкцию. Для запуска введите следующие команды:

```bash
git clone https://github.com/K-a-R-e-N/Mihomo-Install-Script
bash ~/Mihomo-Install-Script/mihomo-setup.sh
#Готово
```

> _В процессе выполнения установщик один раз запросит пароль администратора (`sudo`), после чего выведет центрированную рамку-инструкцию, где вам нужно будет вставить скопированный с сайта `warp-generation.github.io` текст под кнопку **Clash -> AWG 2.0** и нажать `Ctrl + D`._

### УПРАВЛЕНИЕ ТУННЕЛЕМ И ОБНОВЛЕНИЕ КЛЮЧЕЙ
Благодаря интеграции нативного бинарного интерфейса, вам больше не нужно запускать скрипт установки повторно для смены конфигурации. 

**Внимание:** Если при первой установке утилита не запускается напрямую, принудительно выдайте ей права на исполнение в системе следующей командой:
```bash
sudo chmod +x /usr/local/bin/mihomoimport
```

После этого из любого места в терминале вы можете вызывать обновление ключей простой короткой командой:
```bash
mihomoimport
#Готово
```
Утилита сама временно приостановит маршрутизацию, выведет понятную памятку, запишет новые параметры AmneziaWG в провайдер, очистит за собой экран и покажет итоговый отчет сравнения старого и нового IP-адресов.

#### Полезные команды управления сервисом:
* `sudo systemctl status mihomo` — Проверить текущий статус работы фонового процесса туннеля.
* `sudo systemctl restart mihomo` — Принудительно перезапустить службу и обновить сетевую сессию Cloudflare.
* `sudo journalctl -u mihomo.service -f --no-pager` — Просмотр внутренних логов ядра Mihomo в реальном времени.

### УДАЛЕНИЕ СИСТЕМНЫХ ФАЙЛОВ И ТУННЕЛЯ
Для полного удаления ядра Mihomo, конфигурационных файлов провайдеров, фоновой службы `systemd` и очистки глобальных команд, выполните следующую цепочку команд:

```bash
sudo systemctl disable --now mihomo > /dev/null 2>&1
sudo rm -rf /etc/mihomo /usr/local/bin/mihomo /usr/local/bin/mihomoimport /etc/systemd/system/mihomo.service
sudo systemctl daemon-reload
rm -rf ~/Mihomo-Install-Script
#Готово
```
