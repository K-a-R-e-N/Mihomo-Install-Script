# Скрипт автоматической установки ядра Mihomo (AmneziaWG) на Raspberry Pi
_Mihomo Proxy-Provider & Auto-Installer Script_

Профессиональный интерактивный скрипт для автоматического развёртывания и инициализации последней стабильной версии ядра **Mihomo (Clash Meta)** с нативной поддержкой протокола **AmneziaWG**. Скрипт превращает вашу Raspberry Pi в умный сетевой шлюз, который перенаправляет заблокированный трафик через туннель WARP и защищает локальную сеть умного дома от сбоев.

## Реализованные функции

* **Архитектура Proxy-Provider:** Исполняемое ядро полностью отделено от персональных ключей. Конфигурация AmneziaWG вынесена в изолированный провайдер `warp.yaml` (символическая ссылка на активный профиль). Вы можете менять ключи в любой момент без переустановки системы.
* **Поддержка 5 профилей (Multi-Config):** Пять независимых слотов для ключей (`warp_1.yaml` – `warp_5.yaml`). Переключение, импорт и удаление выполняются из панели в одно действие.
* **Фоновый Watchdog:** Пока открыта панель управления, независимый фоновый процесс циклически проверяет доступность сайтов из списка через порт шлюза `7890`. При сбоях на активном профиле система автоматически переключится на следующий заполненный слот и перезапустит ядро — без зависания интерфейса.
* **Панель управления `mihomoutil`:** Интерактивное меню со вложенными разделами и динамическими статусами: пункты запуска/остановки туннеля и автозагрузки сами меняют названия и цвета в зависимости от реального состояния службы. Выверенные отступы под ширину 80 символов и отсутствие эмодзи гарантируют корректное отображение в PuTTY, MobaXterm и Xshell.
* **Защита локальной сети умного дома:** Сетевой стек `gvisor` и правило `GEOIP,lan,DIRECT` исключают домашнюю подсеть из туннеля. Доступ по SSH, VNC, Homebridge Config UI X и работа локальных Zigbee/Wi-Fi устройств сохраняются при любых режимах работы VPN.
* **Сохранность настроек при переустановке:** Перед обновлением инсталлятор копирует все 5 слотов ключей и список сайтов `rules.yaml` в `/tmp/mihomo_bak` и восстанавливает их обратно.
* **Защита ввода от ошибок:** Встроенный парсер автоматически вырезает блок `proxies:` из вставленного текста и разворачивает YAML-якоря. Меню распознаёт команды при забытой русской раскладке, а вставленные ключи сразу стираются с экрана.
* **Однострочный SSH-информер:** При входе по SSH выводится компактная цветная строка со статусом службы, режимом сети и подсказкой вызова панели (`/etc/profile.d/mihomoutil_motd.sh`).
* **Комплексная диагностика:** Автоматический опрос всех доменов из списка через прокси-шлюз по завершении установки и по команде `mihomoutil --check`.

## Требования

* Raspberry Pi (или любой Debian-хост) с 64-битной ОС и правами администратора (`sudo`)
* Системная служба `systemd` (стандарт для Raspberry Pi OS)
* Терминал шириной не менее 80 символов — панель и установщик рассчитаны на эту ширину

---

## Предварительная подготовка

Убедитесь, что на вашей Raspberry Pi установлена актуальная 64-битная ОС (**Raspberry Pi OS / Debian**). Обновите списки пакетов и установите базовые утилиты:

```bash
sudo rm -Rf /var/lib/apt/lists
sudo apt update && sudo apt install git curl wget -y
```

## Установка и первый запуск

Скрипт скачает актуальный релиз ядра Mihomo под архитектуру процессора, создаст конфигурационные файлы, настроит службу `systemd` и установит глобальную команду управления:

```bash
git clone https://github.com/K-a-R-e-N/Mihomo-Install-Script
bash ~/Mihomo-Install-Script/Mihomo-setup.sh
```

> **Примечание по импорту ключей:** во время установки скрипт предложит вставить конфигурацию с сайта `warp-generation.github.io` — текст из раздела под кнопкой **Clash**, целиком (от `warp-common:` до `MATCH,WARP`), и завершить ввод комбинацией `Ctrl + D`. Не копируйте раздел **AWG 2.0** — парсер его не примет. Чтобы пропустить шаг и добавить ключи позже через панель, введите латинскую `S` и нажмите `Enter`.

### Тихий режим (для автоматизации)

Установка без интерактивных вопросов (включается селективный режим обхода, шаг ввода ключей пропускается):

```bash
bash ~/Mihomo-Install-Script/Mihomo-setup.sh --silent
```

## Панель управления

Для запуска интерактивного меню из любого каталога выполните:

```bash
mihomoutil
```

### Структура главного меню

* **`1` – `4`** — Управление списком сайтов (просмотр, добавление по одному или массовым списком, удаление).
* **`5`** — **Профили WARP** (переключение между слотами №1–№5, импорт и удаление ключей, счётчик заполненных слотов).
* **`6`** — Переключение режима сети (селективный: только список сайтов, или глобальный: весь трафик через туннель).
* **`7`** — Запуск / остановка фоновой службы туннеля.
* **`8`** — Управление автозапуском службы при загрузке системы.
* **`9`** — Включение / отключение SSH-информера.
* **`10`** — Тест доступности всех сайтов из списка.
* **`H`** — Справка по ключам командной строки.
* **`U`** — Проверка и установка обновлений панели с GitHub (без переустановки ядра).
* **`L`** — Просмотр живых логов ядра в реальном времени.
* **`0` / `Enter`** — Выход из панели.

### Полезные команды службы

* `sudo systemctl status mihomo` — Проверить состояние фонового процесса.
* `sudo systemctl restart mihomo` — Перезапустить службу и обновить сессию туннеля.
* `sudo journalctl -u mihomo.service -f --no-pager` — Открыть журнал событий ядра.

## Подключение устройств умного дома

Шлюз работает на порту `7890` (mixed-порт: одновременно SOCKS5 и HTTP-прокси) и по умолчанию открыт в локальной сети (`allow-lan: true`). Чтобы увести трафик устройства через туннель, укажите в его настройках прокси:

* адрес: IP-адрес Raspberry Pi в локальной сети
* порт: `7890`
* тип: SOCKS5 или HTTP

Локальные устройства (SSH, VNC, Homebridge, Zigbee-шлюзы) в туннель не попадают — правило `GEOIP,lan,DIRECT` и стек `gvisor` оставляют домашнюю подсеть напрямую.

## Управление из командной строки (CLI)

Утилита поддерживает прямое управление без открытия меню (удобно для сценариев автоматизации умного дома):

* `mihomoutil --help` / `-h` — Вывести справку по всем ключам.
* `mihomoutil --list` — Показать текущий список доменов из `rules.yaml`.
* `mihomoutil --add [домен]` — Добавить сайт в обход (пример: `mihomoutil --add instagram.com`).
* `mihomoutil --remove [домен]` — Удалить сайт из списка обхода.
* `mihomoutil --bulk` — Массовое добавление доменов списком.
* `mihomoutil --check` — Выполнить проверку доступности всех сайтов.
* `mihomoutil --mode-selective` / `--mode-global` — Переключить режим маршрутизации (по списку или весь трафик).
* `mihomoutil --config-num1` .. `--config-num5` — Активировать Профиль №1–№5.
* `mihomoutil --keys-1` .. `--keys-5` — Импортировать ключи в выбранный профиль.
* `mihomoutil --start` / `--stop` — Запустить или остановить туннель.
* `mihomoutil --enable` / `--disable` — Включить или отключить автозагрузку службы.
* `mihomoutil --ssh-enable` / `--ssh-disable` — Включить или удалить SSH-информер.
* `mihomoutil --update` — Обновить только панель с GitHub (ядро не переустанавливается, ключи и список сайтов сохраняются). Панель также сверяет версию установщика и подскажет, когда стоит переустановить его для обновления ядра.
* `mihomoutil --logs` — Вывести логи ядра в реальном времени.

## Диагностика: если что-то пошло не так

* Панель: пункт `10` — покажет, какие сайты доступны, а какие нет.
* `sudo systemctl status mihomo` — жива ли служба.
* `mihomoutil --logs` или клавиша `L` в панели — журнал ядра: ошибки парсинга конфигурации видны там первыми.
* Ошибка вида `[ОШИБКА] Блок proxies: не найден` при импорте — вы скопировали раздел AWG 2.0; нужен текст под кнопкой Clash, целиком.
* Файлы ключей хранятся с правами `600` — читать их может только администратор.

## Полное удаление

Чтобы полностью удалить ядро Mihomo, все конфигурации, службу `systemd`, SSH-информер и файлы скрипта:

```bash
sudo systemctl disable --now mihomo > /dev/null 2>&1
sudo rm -f /etc/profile.d/mihomoutil_motd.sh
sudo rm -rf /etc/mihomo /usr/local/bin/mihomo /usr/local/bin/mihomoutil /etc/systemd/system/mihomo.service
sudo systemctl daemon-reload
rm -rf ~/Mihomo-Install-Script
```
